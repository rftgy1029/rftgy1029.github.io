# rftgy1029.github.io

https://rftgy1029.github.io/ 첫 화면(생활 계산기 모음) 페이지입니다.

- `index.html` — 계산기 목록 (새 계산기를 만들면 여기에 추가)
- `sitemap.xml`, `robots.txt` — 검색 사이트용 (도메인 첫 화면에 있어야 동작)
- 검색 사이트 소유확인 태그(네이버 등)는 `index.html`의 `<head>`에 넣습니다. 지우면 확인이 풀립니다.
- 나중에 애드센스를 신청하면 `ads.txt`도 이 저장소 최상위에 둡니다.

계산기 소스: [alba-pay-calculator](https://github.com/rftgy1029/alba-pay-calculator)
